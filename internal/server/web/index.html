Сбор региона (ручной режим)

Односторонний импорт из Яндекс-дампа → unverified-терминалы в каноне. Затем валидация через внешние API и ручное одобрение во вкладке Терминалы. Сбор рейсов — cache-first (кэш валиден), недостающее добирается через API по квоте. Городские остановки (bus_stop) — только если осознанно хотите плотное городское покрытие: их ~126 тыс. в дампе, расписаний в кэше для них нет — offline их не соберёт, а онлайн сожжёт квоту.
классы станций (пусто = терминальные):
1 — Яндекс-дамп (локальный файл, без сети) • 2 — Яндекс Rasp (кэш → API по квоте) • 3 — OSM/Overpass (сеть, без расписаний)
удаляет терминалы, рейсы, маршруты, стопы, staging, историю синков и ревью; каркас (users/keys/jobs/places/квоты) и кэш Яндекса на диске не трогаются

Review queue — зачем?

Сюда попадают объекты с confidence<0.6, missing_coords, duplicate_ambiguous, conflicts_with_confirmed. Без ручной проверки они не попадут в канон/GTFS/маршрут — иначе «мусор» испортит find_route. Оператор правит в Терминалы → is_locked → объект выходит из очереди.
