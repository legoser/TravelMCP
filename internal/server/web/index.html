Review queue — зачем?

Сюда попадают объекты с confidence<0.6, missing_coords, duplicate_ambiguous, conflicts_with_confirmed. Без ручной проверки они не попадут в канон/GTFS/маршрут — иначе «мусор» испортит find_route. Оператор правит в Терминалы → is_locked → объект выходит из очереди.
